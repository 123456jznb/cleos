# Cleos

一个安卓原生（Kotlin + Jetpack Compose）的陪伴聊天 App，界面是自己写的液态玻璃。
除了和 TA 聊天（自己填 API），也能写日记（可以贴图）、记待办。数据都只存在手机上。

- **聊天**：OpenAI 兼容接口（DeepSeek / OpenAI / 硅基流动 / Kimi / OpenRouter……），流式输出、可停止、失败可重试。可以有多段对话。
  能发图片（一次最多 4 张）：模型要能看图；看不了图的模型会自动只发文字，并在聊天里说一声。
- **好几个 TA**：每个 TA 有自己的名字、头像、性格和模型，各聊各的、各写各的日记，互相看不到。在主页顶上或聊天页的标题上切换、添加。
  你的日记和小秘密，对每个 TA 规矩都一样。Key 跟着接口地址存：同一个服务上的几个 TA 共用一个，填一次就够。
- **分几条发**：TA 想分开说的时候，会一条一条地发（`send_message` 工具，一次调用一个气泡），像聊天软件里那样。
  模型直接回复文字也照常显示，所以不支持工具的模型最多是不拆开，不会不说话。
- **TA 能动手**：在聊天里说一声，TA 会调用工具去做：记待办、看清单、改日期、打勾，读你的日记（默认关着），写自己的日记，问你要小秘密，拿你发来的图或一个表情换自己的头像，查天气（open-meteo，不要 Key）。
  做了什么在聊天里有一行小字。每项都能在设置里关掉；模型不支持工具调用的，会自动不带工具，聊天照常。
- **日记**：文字和图片按写的顺序排，图插在光标处；边写边自动保存。TA 也有自己的日记，和你的写在同一个本子里，标着是 TA 写的（你能看，改不了）。
- **小秘密**：日记可以锁上。TA 知道有，但看不到标题和内容；想看会在聊天里发一张卡片问你，你点「给 TA 看」才给看这一次，日记还是锁着。
- **记忆**：TA 自己决定记什么（`memory` 工具：打开、记下、改、忘掉），分五类：关于你的四类（基本情况、在意的事、最近、相处方式）和关于它自己的。
  每条的一句摘要跟着每条消息带着，细节要用时才打开，所以记得再多，每轮也多花不了多少。主页「记忆」里能看、能改、能钉住
  （钉住的 TA 只能看），也能自己加一条。每个 TA 各记各的。
- **信**：每个 TA 和你一个信箱（主页上的「信」）。你写信寄出，TA 一定回，但回信默认过 1～6 小时才到，夜里的推到第二天早上；
  TA 也会不定期自己写来：默认隔至少 5 天、这段时间有话可写才写，没什么可写就不写。信只有你们俩看得到，聊天里提到信 TA 也接得上。
  回信多久到（从「一写好就到」到一天，在范围里随机）、夜里来不来信、TA 自己写信至少隔几天，都在设置「写信」下面改。
  信是提前写好、到点才出现的，不靠后台任务（很多手机会把后台掐掉）：App 回到前台时，该写的就写。
- **待办**：可加日期和备注，完成的收起来，长按删除可撤销。
- **从别的 App 搬过来**：认得 [phone-ai-assistant](https://github.com/jqzhang921-sudo/phone-ai-assistant) 导出的备份。
  那边的对话和它写的日记放进一个新的 TA，它记得的关于你的事写进这个 TA 的性格；图片（那边的备份里只有名字）和工具调用不带。
- **主页**：你和正在聊的这个 TA 的头像、名字（头像从相册选，拖动缩放裁成圆的），认识的第几天（默认从第一句话算，可以改），聊过多少句、TA 写了多少篇日记。头像也可以放在聊天气泡旁边。

需要 Android 10 以上；液态玻璃的折射要 Android 13 以上，12 只有模糊，更早的只有半透明。

## 液态玻璃是怎么做的

全在 `app/src/main/java/com/cleo/cleos/glass/`。

1. **背景录下来**（`Backdrop.kt`）：页面内容在画的时候同时录进一个 `GraphicsLayer`。玻璃再把这层画一遍（画的是 RenderNode 引用，不是拷像素），所以列表一滚，玻璃后面同一帧就跟着变。
2. **一个 AGSL 着色器做完所有事**（`GlassShader.kt`）：圆角矩形的 SDF 算出每个像素离边多远；边缘按四分之一圆的斜面弯折采样点（折射）；红蓝两个通道弯得不一样多（色散）；再加饱和度、着色、沿边的高光、手指按下处的光、外面的阴影。模糊在它之前做（`RenderEffect` 链）。
3. **按下会鼓起来**：不是把控件放大（那样背景也跟着放大，对不上），而是在着色器里把轮廓长出去。
4. **Tab 栏的透镜**（`GlassTabBar.kt`）：选中的那块本身是一块玻璃，看的是 Tab 栏自己。按住它会变大、变清、放大下面的字，拖动时按速度拉长，松手弹到最近的一格。
5. **设置 → 玻璃实验室** 可以拖一块玻璃、调每个参数看效果。

## 工具调用是怎么接的

`app/src/main/java/com/cleo/cleos/ai/`。一次回复是个循环：模型回文字、调用或两者都有 → 执行调用，结果送回去 → 模型接着说，直到它不再调用（最多 5 轮）。

- 每一步都当场存进数据库（说的话、调用、每个结果），所以停止、崩溃之后记录和实际做过的事对得上；「重新回答」从结果接着答，不会把同一条待办再加一遍。
- 历史里调用和结果必须成对：窗口从中间截断、停在工具执行中间，都会留下落单的一半，发出去之前配好对，落单的去掉（`Prompt.pairCalls`）。
- 推理模型（DeepSeek 等）在同一轮里的思考要跟着调用送回去，之前轮次的不送。
- 小秘密不靠「记得过滤」：给模型读日记的查询本身就带着 `secret = 0`，锁着的那篇连标题都不会进请求。
  别的 TA 的日记也一样：查询只认你的和这个 TA 自己写的（`companionId`），别人写的进不了请求。
- 流式的调用参数是一段段来的，各家拼法不同（有的不带 index、有的整段给、有的参数给成对象），`StreamParser` 都认。

几条踩过的坑写在代码注释里（为什么要 overscan、为什么采样点要夹在屏幕内、为什么背景副本只录不画、为什么页面切换用淡入淡出不用滑动）。

## 构建

用 Android Studio 自带的 JDK（21）：

```
./gradlew assembleRelease
```

签名读根目录的 `keystore.properties`（已在 `.gitignore` 里，别提交）：

```
storeFile=/path/to/upload-keystore.jks
storePassword=...
keyAlias=...
keyPassword=...
```

有这个文件时 debug 和 release **用同一把钥匙签**：换钥匙装不上，唯一的办法是卸载，而卸载会清掉 App 里的全部数据。

国内网络拉 Google Maven（dl.google.com）要代理，可以在命令行加
`-Dhttps.proxyHost=127.0.0.1 -Dhttps.proxyPort=7890`。
